Адаптивний веб-застосунок **FilmHub** — онлайн-каталог фільмів (лабораторна робота №1 з дисципліни «Web-орієнтовані технології. Backend-розробки»).

## Структура проєкту
- `index.html` — головна сторінка  
- `css/style.css` — стилі та адаптивність  
- `js/script.js` — бургер-меню та анімації  
- `assets/images/` — постери фільмів  

## Як запустити
1. Відкрийте папку у VS Code.
2. Встановіть розширення **Live Server**.
3. Клікніть правою кнопкою на `index.html` → **Open with Live Server**.

Проєкт розроблено з використанням Flexbox/Grid, media queries та Conventional Commits.
