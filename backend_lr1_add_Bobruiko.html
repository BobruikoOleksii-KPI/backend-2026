Виконання додаткової частини лабораторної роботи №1

Виконані завдання

  1. Створено Node.js проєкт та встановлено Express.js.
  2. Реалізовано базовий HTTP-сервер з повідомленням «Hello from Node.js server».
  3. Створено маршрут GET /students, який повертає список студентів у форматі JSON.
  4. Реалізовано маршрут POST /students для додавання нового студента (поля: id, name, group).
  5. Реалізовано маршрути PUT /students/:id та DELETE /students/:id для оновлення та видалення студента.

Ключовий код сервера (server.js)

const express = require("express");
const app = express();
app.use(express.json());

let students = [ ... ];

app.get("/students", (req, res) => res.json(students));
app.post("/students", (req, res) => { ... });
app.put("/students/:id", (req, res) => { ... });
app.delete("/students/:id", (req, res) => { ... });

app.listen(3000, () => console.log("Server started on port 3000"));
